# Frontend — Attendly (SvelteKit)

See the root [`README.md`](../README.md) and
[`docs/developer/frontend-setup.md`](../docs/developer/frontend-setup.md) for setup,
commands, and architecture.

Quick start:

```sh
npm install
cp .env.example .env
npm run dev
```

This directory is a SvelteKit 2 / Svelte 5 (runes) app. Real API by default;
set `PUBLIC_MOCK_MODE=true` in `.env` to use fixtures.
